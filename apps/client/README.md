# @staf/client

Vue public application for STAF.

## Project Setup

```sh
pnpm install
```

### Compile and Hot-Reload for Development

```sh
pnpm --filter @staf/client dev
```

### Type-Check, Compile and Minify for Production

```sh
pnpm --filter @staf/client build
```

### Lint with ESLint

```sh
pnpm --filter @staf/client lint
```
