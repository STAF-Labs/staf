# Автоматическое распознавание лицензии проекта

Нужно реализовать предварительное распознавание лицензии по загруженному файлу на этапе создания
проекта.

Краткий сценарий:

- Vue admin передает выбранный файл в Laravel API;
- Laravel вызывает отдельный Go-сервис;
- сервис возвращает распознанное название либо отсутствие надежного совпадения;
- название предварительно заполняется в форме и остается доступным для ручного изменения;
- ошибка распознавания не блокирует создание проекта;
- в базе данных сохраняются только название и файл лицензии, без статуса обработки.

Архитектура, контракт и рассмотренные альтернативы зафиксированы в
[`ADR 0005: Микросервис распознавания лицензий`](../adr/0005-license-recognition-microservice.md).
