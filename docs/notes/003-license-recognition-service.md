# Автоматическое распознавание лицензии проекта

Статус: отменено.

От загрузки отдельного файла лицензии отказались. В проекте хранится `licence_name`, а пользователь
выбирает лицензию из SPDX-справочника через селектор. Поэтому предварительное распознавание файла и
отдельный Go-сервис сейчас не требуются.

История рассмотренного решения сохранена без изменений в
[`ADR 0005: Микросервис распознавания лицензий`](../adr/0005-license-recognition-microservice.md).
