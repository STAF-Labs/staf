# Кнопка «Вид» на странице проектов

Статус: требуется уточнение UI.

На index-странице проектов нужно добавить кнопку «Вид».

Реализовано: карточка проекта на index-странице ведёт на `projects.show`, где открывается страница
просмотра проекта.

## Открытые вопросы

- Нужно отдельно продумать внешний вид второго режима отображения проектов — горизонтальных
  карточек. Текущая задача касается организации карточек на странице, а не внешнего вида фильтров.
- Первый режим отображения — обычные квадратные карточки — должен оставаться визуально стабильным и
  не должен ломаться правками горизонтального режима.
- Для горизонтальных карточек нужно отдельно согласовать ширину строки, фон области изображения,
  внутренние отступы, положение статуса, даты и action-кнопок.
