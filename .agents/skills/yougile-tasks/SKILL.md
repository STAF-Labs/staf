# Yougile Tasks

## Workflow

1. Использовать шаблон `docs/tasks/staf-yougile-tasks-template.md`.
2. Создавать рабочие файлы в `docs/tasks/` с именем `TASKS-{date}-name-kebab-case.md`.
3. Подставлять `{date}` как сегодняшнюю дату в формате `YYYY-MM-DD`.
4. Выбирать `name-kebab-case` по теме задач: коротко, латиницей, без пробелов.
5. Внутри одного календарного дня работать в одном существующем файле `TASKS-{date}-*.md`.
6. Если на сегодняшнюю дату уже есть несколько файлов, выбирать наиболее близкий по теме имени. Если тема неоднозначна, кратко сообщить, какой файл выбран.
7. Если файла на сегодняшнюю дату нет, создать новый файл из шаблона и заменить заголовок `# TASKS: {date}` на фактическую дату.
8. Не менять файлы задач за другие даты без прямой просьбы пользователя.

## Task Format

Сохранять структуру шаблона:

- главная задача начинается с `## Главная задача N`;
- подзадачи начинаются с `### Подзадача N.M`;
- каждую задачу заполнять полями `Заголовок`, `Приоритет`, `Тип`, `Описание`;
- допустимые приоритеты: `критический`, `высокий`, `средний`, `низкий`, `беклог`;
- допустимые типы: `задача`, `SEO`, `Общий`, `Баг`, `Веха`.

Писать задачи на русском языке. Не добавлять новые поля вроде статуса, исполнителя или оценки, если пользователь явно этого не попросил.
